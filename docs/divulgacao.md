## Texto para apresentar o portfólio

No meu portfólio, o ServiceScheduler mostra como trabalho com C#, ASP.NET Core e SQL Server. O desafio é evitar reservas conflitantes respeitando disponibilidade, regras de negócio e privacidade.

Também apresento uma API de atendimento com autenticação, auditoria e atualização em tempo real, um portal de governança SQL e uma central para organizar o desenvolvimento assistido por IA.

Em cada projeto, apresento o problema, as decisões técnicas e as entregas. O código, os testes e as instruções de execução estão nos repositórios. As imagens de interface do portfólio são ilustrativas.

## Distribuição

1. Adicione o portfólio à seção Destaques do LinkedIn e às informações de contato.
2. Destaque no GitHub os repositórios que aparecem na página inicial.
3. Publique um projeto por vez: problema, decisão técnica, demonstração e link para a página do projeto.
4. Use demonstrações reais quando disponíveis. Identifique imagens conceituais como ilustrações; elas não comprovam uso em produção.
5. Depois de publicar, cadastre o sitemap no Google Search Console e confira a prévia do link no LinkedIn Post Inspector.

Não há promessa de posição nas buscas ou de volume de visitas. O objetivo é tornar a especialidade e as evidências do trabalho mais fáceis de encontrar e avaliar.
